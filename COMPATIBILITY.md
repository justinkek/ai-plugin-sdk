# Where a plugin built with ai-plugin-sdk can be installed

(audience: humans)

Supported means everything the SDK writes reaches a session: the hooks, the
skills and the settings. Partial means some of it does not, and the note
under the tables says which.

**What is missing where it says Partial**

- **Claude Chat** - No hook runs, so a plugin reaches a conversation only through its skills.
- **Pi** - Skills load from ~/.agents/skills and an extension puts none there, so a plugin's skills do not arrive.
